# 电视端儿童界面设计（手账贴纸）

2026-11-05 在四个方向（童话小路、手账贴纸、星际航线、果冻按钮）中选定**手账贴纸**。以后的学习游戏列表、针对性学习入口都按这里的规则做。

## 功能契约

- 3 秒内：孩子看出现在能玩什么、遥控器选中的是哪个。
- 主动作：选中「学习」并进入。次要：贴纸册，以后的学习游戏。
- 大人的东西（剩余时间、家长入口）存在，但不抢孩子的注意。

## 视觉

| 元素 | 规则 |
|---|---|
| 纸面 | 主题 `bgTop` 向奶油色混 60% 作底，加浅色点阵（26dp 间距）。静态绘制，不做动画 |
| 入口 | 白色异形贴纸底（四角半径不等），顶部一条斜纹胶带，整体倾斜 -5°～4°，错落摆放。不用方框、不用渐变卡片 |
| 胶带 | 取主题 `blobs` 的颜色，深浅两色 45° 斜纹 |
| 字体 | 标题和入口名用 ZCOOL 快乐体子集（`assets/fonts`，OFL）；说明文字用系统字体。新增手写字要重新生成子集 |
| 强调 | 标题下是一道主题 `star` 色的荧光笔底；选中入口下画出手绘波浪线（主题 `accent`） |
| 剩余时间 | 右上角便利贴「还能看 N 分钟」；不足 20% 时数字变红并不时抖动；守护暂停时隐藏 |
| 家长入口 | 右下角半透明小锁，选中才变清楚；不显示缺权限提示 |
| 今天的星星 | 左下角虚线圆印章，每学完一轮盖一颗 |

## 动效

- 入场（只在第一次进入）：吉祥物探头，荧光笔从左往右划出，贴纸一张张"拍"上纸面，便利贴掉下来。
- 选中：贴纸摆正、抬起（上移 16dp、放大 1.12、阴影加深），图标跳一下后轻轻呼吸，波浪线画出来，说明文字淡入。用回弹插值。
- 按确认：先压到 0.95 再弹回，然后进入。
- 待机：只有吉祥物和选中贴纸的图标在动（电视 4A 性能有限）。
- 新星星：像盖章一样从大到小落下。

## 交互

- 第一次进首页时底部浮出一句操作提示，孩子挪动或 8 秒后淡出，只出一次。
- 遥控器路径写死：入口之间左右切换，往下到家长锁，锁往上回「学习」。
- 选中入口时朗读一句介绍（停留约 0.5 秒后才读，刚进页面的自动聚焦不读）。

## 不要

- 方框卡片、整块渐变色块、长句说明文字、给孩子看规则。
- 同时有多个循环动画。
